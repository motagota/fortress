# Fortress — Full Rebuild on a Layered Floor/Wall World

## Context

The current world model is a 16×16 *projected 2D* map that gets stacked/imported into a
"chunked 3D" store (`chunk_addressing.gd`, `chunked_world_store.gd`, `packed_cell_codec.gd`,
`chunked_world_read_adapter.gd`). The whole simulation (`simulation.gd`, 2114 lines) runs in
projected 2D `Vector2i` space with `Vector3i` `world_cell` shims bolted on, and the renderer
greedy-meshes 16-cube chunks for an isometric orbit camera. `grid_world.gd` (the projection
source the tests still reference) has already been deleted, so the model is mid-demolition.

You've decided to **rebuild the game from scratch** on a fundamentally different world:

- **48×48 cells per layer**, ~**100 vertical layers** of interleaved geological bands
  (sky/surface, upper earth, caverns, magma sea + bottom).
- **Top-down view, one layer at a time.** WASD pans the camera; **E/C** move the active layer
  up/down. Cells are 1×1×1. No chunks — we only ever work on a single layer.
- **Each cell carries a floor and a wall** (Dwarf-Fortress tile model) plus extras: stairs/ramps,
  liquids (water/magma, level 0–7), a plant/tree occupant, a building slot, and hidden ore.
- The **surface is exposed to air** → trees and food plants grow there.
- **Full feature parity** with today's gameplay (units, jobs, stockpiles, construction,
  mining, hauling, workshops/cooking, needs), rebuilt natively on the new model — no 2D shims.
- **Determinism is core**: seeded RNG, tick-ordered command queue, canonical snapshot + state
  hash, replay, and save/load.
- **TDD with GUT**; target **≥10 ticks/second**.

Outcome: a clean, single-layer, top-down colony sim on a deep layered world, deterministic and
tested, with the chunk/projection machinery removed entirely.

> Vertical numbers below are **tunable defaults** chosen to match your stated ranges; adjust at
> approval. Bands overlap/interleave (generated as layered passes), as requested.

## Target architecture

### Coordinates & constants (`scripts/simulation/world_constants.gd` — rewrite)
- Horizontal `x ∈ [0,48)`, `z ∈ [0,48)`. Vertical layer `y ∈ [0,100)`, **higher y = up** (Godot
  Y-up); `y=99` top sky, `y=0` bottom. `Vector3i(x, y, z)` is the cell address.
- `WIDTH=48`, `DEPTH=48`, `LAYER_COUNT=100`.
- **Band table** (overlapping Y-ranges, generated by separate passes; default mean surface ≈ y75):
  - `sky` (open air, no floor until ground) — top, down to per-column surface.
  - `surface` (grass floor, grows plants/trees) — ~3 layers at the column surface.
  - `upper_earth` (dirt/soil + clay near water) — roughly y40–y74.
  - `stone` (soft/hard rock + ore) — roughly y10–y55, **overlaps** upper_earth/caverns.
  - `caverns` (open space carved within stone, may hold water) — roughly y20–y50.
  - `magma_sea` (magma liquid) + `bedrock` floor — bottom ~y0–y12.
- Keep material/strata/mining-tier/terrain enums; extend with `MATERIAL_MAGMA`, plant/sapling
  materials, stair/ramp kinds.

### Cell model (`scripts/simulation/cell.gd` — rewrite)
A plain struct (RefCounted or packed-field record) with:
`floor_material` (`""`=open shaft, else solid floor you stand on), `wall_material`
(`""`=no wall, else solid fill blocking movement/vision), `liquid_type`+`liquid_level (0–7)`,
`plant` (`{type, growth}` or `""`), `building_id`, `hidden_ore` (`{material,item_type,quantity}`),
`stair` (`none|up|down|up_down|ramp`), `band`/`strata_key`, `mining_tier_required`,
`designation` (`none|mine|chop|gather|channel|build_stair`), `exposure` (`sky|dark`).
- **Derived:** `walkable = floor_material != "" and wall_material == "" and liquid_level < 4`.
- `to_canonical_dict()` for snapshot/hash; deterministic field order.

### World store (`scripts/simulation/world.gd` — new, replaces chunk store)
Dense, no chunks. Per-layer flat arrays indexed `i = x + z*WIDTH`; layers in a
`Dictionary[int→layer]` or `Array[LAYER_COUNT]`. API:
`get_cell(Vector3i)`, `set_cell(Vector3i, fields)`, `in_bounds`, `cells_on_layer(y)`,
`neighbors_for_movement(Vector3i)` (4-dir same layer + stair/ramp up/down), `to_canonical_array()`.
Designed so a tick touches only active agents/jobs, never all 230k cells.
- **Delete:** `chunk_addressing.gd`, `chunked_world_store.gd`, `packed_cell_codec.gd`,
  `chunked_world_read_adapter.gd`, `worldgen_diagnostics.gd`, and the `.uid` siblings.

### Worldgen (`scripts/simulation/worldgen.gd` — rewrite)
Pure, seeded, deterministic passes writing into `World`:
1. **Surface elevation** per `(x,z)` from layered value noise (continental/broad/regional) →
   smoothed surface y + slope.
2. **Base column fill:** sky above surface (open), surface band (grass floor), upper_earth
   (dirt/clay), stone (soft→hard with depth), bedrock floor. Boundaries jittered per column.
3. **Cavern pass:** carve connected open pockets within the cavern Y-range (clear wall, keep/scatter
   floor); some flagged `exposure=sky`-equivalent "open". Optionally water at cavern floors.
4. **Liquid pass:** magma fills `magma_sea`; cavern lakes get water level 7.
5. **Ore pass:** hidden coal/copper in soft rock, iron in hard rock (+ silver/gold/oil deeper,
   gated), as `hidden_ore` on rock cells.
6. **Flora pass:** surface exposed-floor cells seed trees (oak/pine), berry bushes, wild wheat.
   Hooks for later growth ticks.
- Fallbacks guarantee ≥1 of each starter resource near spawn (as today).

### Simulation (`scripts/simulation/simulation.gd` — rewrite, native 3D)
Same systems, no projected-cell shims; everything is `Vector3i`.
- **Units** (`unit.gd`): needs (hunger/energy/morale), skills, allowed_jobs, job-type priorities,
  state machine, inventory. Position is `Vector3i`.
- **Jobs** (`job.gd`, `job_board.gd`): `CHOP_TREE, GATHER_STONE, GATHER_FOOD, MINE_WALL,
  CHANNEL_FLOOR, BUILD_STAIR, HAUL_ITEM, BUILD_CONSTRUCTION, COOK_MEAL`. Best-job selection by
  priority→distance→id (reuse existing logic).
- **Pathfinding:** A* (or BFS) over `World.neighbors_for_movement`; vertical only through
  stairs/ramps; blocked by walls and deep liquid. Replaces `_path_between_world_cells` &
  `_movement_world_neighbors`, deleting all `projected_cell` variants.
- **Mining/terrain ops:** `MINE_WALL` removes wall→drops material item + reveals `hidden_ore`;
  `CHANNEL_FLOOR` removes floor (opens shaft down); `BUILD_STAIR` adds stair connector; deep-mining
  collapse hazard retained via `event_rng`.
- **Stockpiles** (`stockpile.gd`, `zone.gd`): per-layer zones, accepted types, storage modes,
  resize handles, overlap checks.
- **Construction/workshops** (`construction_record.gd`, `building_definition.gd`): wall_block,
  kitchen (3×3 workshop), cook_meal recipe; blueprint validation, resource reservation, build jobs.
- **Needs/eating/hauling**: hunger increment, eat stored meal/food, pickup→deliver haul phases,
  stockpile→stockpile rebalancing.
- **Determinism:** keep `deterministic_rng.gd` and the tick-ordered `command_queue`
  (`_apply_due_commands`, `_compare_commands`). `canonical_snapshot()` + `state_hash()` rebuilt for
  the new world. Commands: designations for chop/gather/mine/channel/stair, stockpile
  designate/resize/mode, place blueprint, queue recipe, set unit priority.
- **Save/load** (new `scripts/simulation/save_game.gd`): write `canonical_snapshot()` JSON to
  `user://saves/…`; `load_game()` restores world + entities + RNG + queue; round-trip equals
  original `state_hash()`.

### Presentation
- **Renderer** (`scripts/presentation/world_renderer.gd` — rewrite): draw only the **active layer**
  as a 48×48 tile grid — floor color, wall overlay, liquid tint, plant/tree, building, designations,
  then items/units on that layer; render the layer **below** dimmed for depth cues. Remove all
  greedy-chunk meshing. Provide `set_active_layer(y)` and `ray_to_cell` against the active-layer
  plane.
- **Camera** (`scripts/presentation/camera_controller.gd` — rewrite): **orthographic top-down**.
  WASD pans X/Z, wheel zooms (ortho size), **E/C** call into Main to change active layer. Drop orbit.
- **Main** (`scripts/main.gd` — rewrite): top-down mouse picking onto the active layer; tool modes
  (inspect/chop/gather/mine/channel/stair/stockpile/kitchen); E/C layer change; feed `SimClock` at
  base interval **0.1s (10 TPS)**.
- **HUD** (`scripts/ui/game_hud.gd` + `scenes/ui/GameHud.tscn`): layer indicator (`Layer y/100`),
  tool buttons incl. new channel/stair, speed/pause, jobs/workers panels; remove worldgen-diagnostics
  panel (its backing script is deleted). `sim_clock.base_tick_interval_seconds = 0.1`.
- **Scenes:** update `scenes/Main.tscn` (ortho `Camera3D` or `Camera2D`-style top-down),
  `scenes/world/WorldRoot.tscn`, `GameHud.tscn`. Keep `UnitView.tscn`/`BuildingView.tscn`, restyle
  for top-down.

  full 48×48×100 world ticks ≥10/sec headless.
